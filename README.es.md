## 📘 Descripción general

Este branch está dedicado a la integración de **OpenPLC** con **Kontrolog Max** y **Kontrolog Mini**, ofreciendo a los usuarios la posibilidad de implementar controladores lógicos programables abiertos en ambas versiones del Kontrolog.

Con esta rama tendrás acceso a todo lo necesario para aprovechar las ventajas de OpenPLC junto al hardware robusto y versátil de Kontrolog.

> ✅ **Ideal para estudiantes, profesionales, técnicos, integradores y empresas que deseen combinar la flexibilidad de OpenPLC con la potencia del Kontrolog.**

---

## 🚀 ¿Qué encontrarás en este branch?

* 📂 Archivos y configuraciones necesarias para usar OpenPLC con tu Kontrolog.
* 🛠️ Herramientas esenciales que necesitarás para preparar tu Kontrolog en un entorno configurable similar al de un PLC estándar.
* ⚙️ Recomendaciones para la asignación de pines GPIO según la distribución de la ESP32 integrada.
* 🔧 Archivos que deberán reemplazarse para asegurar la correcta integración entre OpenPLC Editor y Kontrolog.
* 🎬 Tutoriales y ejemplos prácticos para las versiones **Max** y **Mini**.

---

## 🎯 Beneficios de integrar OpenPLC con Kontrolog

* 🧩 **Flexibilidad**: aprovecha la programación en Ladder, ST, IL o FBD desde OpenPLC Editor.
* ⚡ **Compatibilidad**: implementa OpenPLC en las versiones **Max** y **Mini**.
* 🌐 **Accesibilidad**: entorno abierto y multiplataforma.
* 📈 **Versatilidad**: ideal para automatización industrial, prototipado, formación académica e IoT.
* 🔗 **Soporte ampliado**: vinculación directa a la [documentación oficial de OpenPLC](https://www.openplcproject.com/).
