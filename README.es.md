# Kontrolog en modo Full-Code: BSP y Recursos para Desarrollo.

![FullCode](https://github.com/user-attachments/assets/434381ca-93ab-4840-a398-e471c020eb8a)

📄 **Disponible en otros idiomas**: [English version](./README.md)

Bienvenido a la rama **Full-Code** del proyecto Kontrolog de **Omicron IoT Solutions**.
Este entorno está diseñado para usuarios avanzados y desarrolladores que desean trabajar directamente con el código fuente y los paquetes de soporte de placa (**BSP**) de **Kontrolog Max** y **Kontrolog Mini**.

---

## 🧰 ¿Qué incluye este branch?

* ✅ BSP completo (Board Support Package) para ambas versiones.
* ✅ Guía de instalación para usar con **PlatformIO** en **Visual Studio Code**.
* ✅ Ejemplos de uso y tutoriales.
* ✅ Documentación disponible en **inglés y español**.

---

## 🎯 Público objetivo.

Este entorno está pensado para:

* 🔧 Desarrolladores que deseen modificar o extender el firmware.
* 🧠 Usuarios avanzados que necesiten control total sobre el funcionamiento del dispositivo.
* 🧪 Integradores que quieran llevar Kontrolog a proyectos personalizados o experimentales.

---

## ⚙️ Entorno de desarrollo.

Se recomienda trabajar con:

* **PlatformIO** (como extensión de Visual Studio Code).
* Git (para clonar o bifurcar este branch).
* Conocimientos básicos de programación embebida.

---

## 📦 ¿Cómo empezar?

Revisa los archivos README internos de este branch (disponibles en inglés y español) donde encontrarás:

* 📦 Estructura del BSP.
* ⚙️ Pasos de instalación.
* 🧪 Ejemplos de uso.
