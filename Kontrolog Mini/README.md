## 📘 Overview:

This repository contains instructions, manuals, schematics, packages, and examples to program your **Kontrolog Mini** device, tailored to the functions that best suit your application.

The **Kontrolog Mini** is a programmable controller based on **ESP32** technology, designed for real-time remote monitoring and control of various processes with high security and precision requirements. It is compact, efficient, and can be programmed in **No-Code** or **Full-Code** mode.

## ⚙️ Key technical features:

* 🔌 **Inputs:**

  * 2 configurable inputs:

    * Analog: 4–20 mA / 0–10 V.
    * Temperature: NTC 10K – 3950.
    * Digital 1/0.
    * Ambient temperature and humidity sensor.
    * Pulse counter.

* 🔁 **GPIO:**

  * 4 GPIO ports configurable as input/output or for buses (I2C, SPI, UART).

* 🔋 **Power supply:**

  * 12–28 VDC input with voltage measurement.

* 💬 **Communication:**

  * Modbus RTU port (RS-485, master).
  * Communication module slot:

    * LoRaWAN™, Sigfox, or built-in WiFi.

* 🚨 **Alarms:**

  * Local visual and audible alarms.
  * Remote alerts via SMS, voice message, email, and Telegram (via the platform).

* ⚡ **Outputs:**

  * 2 normally open relay outputs, 12 A @ 240 VAC.

* 🖥️ **Local interface:**

  * USB Type-C port (programming, simulation, power supply).
  * 4.3” color touchscreen LCD HMI for configuration and visualization.

* 🧠 **Embedded control functions:**

  * Remote commands.
  * ON/OFF with hysteresis.
  * Timer.
  * Output activation by associated sensor.
  * Remote alarm.
  * Event counter.
  * PID control.

The system is delivered ready to use with the selected communication modules. All components can be configured as needed and integrated with a web/mobile platform for remote monitoring.
