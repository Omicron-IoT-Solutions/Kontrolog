## 📘 Descripción general:

Este repositorio contiene instrucciones, manuales, esquemas, paquetes y ejemplos para programar tu dispositivo **Kontrolog Mini**, adaptado a las funciones que mejor se ajusten a tu aplicación.

El **Kontrolog Mini** es un controlador programable basado en tecnología **ESP32**, diseñado para el control y monitoreo remoto y en tiempo real de diversos procesos con altos requisitos de seguridad y precisión. Es compacto, eficiente y puede programarse en modo **No-Code** o **Full-Code**.

> ✅ **Tecnología accesible para automatización confiable.**

## ⚙️ Características técnicas destacadas:

* 🔌 **Entradas:**

  * 2 entradas configurables como:

    * Analógica: 4–20 mA / 0–10 V.
    * Temperatura: NTC 10K – 3950.
    * Digital 1/0.
    * Sensor de temperatura y humedad ambiental.
    * Contador de pulsos.

* 🔁 **GPIO:**

  * 4 puertos GPIO configurables como entrada/salida o para buses (I2C, SPI, UART).

* 🔋 **Alimentación:**

  * Entrada de 12–28 VDC, con medición de voltaje.

* 💬 **Comunicación:**

  * Puerto Modbus RTU (RS-485, maestro).
  * Puerto para módulo de comunicación:

    * LoRaWAN™, Sigfox o WiFi (integrado).

* 🚨 **Alarmas:**

  * Visuales y audibles locales.
  * Alertas remotas vía SMS, voz, correo electrónico y Telegram (desde la plataforma).

* ⚡ **Salidas:**

  * 2 salidas tipo relé (NO), 12 A @ 240 VAC.

* 🖥️ **Interfaz local:**

  * Puerto USB tipo C (programación, simulación, alimentación).
  * Pantalla HMI LCD táctil a color de 4.3” para visualización y configuración.

* 🧠 **Funciones de control embebidas:**

  * Comandos remotos.
  * ON/OFF con histéresis.
  * Temporizador.
  * Activación de salida por sensor asociado.
  * Alarma remota.
  * Contador de eventos.
  * Control PID.

El sistema se entrega listo para usar con los módulos de comunicación solicitados. Los complementos se configuran según necesidad y se puede vincular con una plataforma web/móvil para monitoreo remoto.
