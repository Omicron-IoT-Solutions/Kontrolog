## 📘 Descripción general:

Bienvenido a la rama **No-Code** del proyecto Kontrolog. Esta sección está pensada para usuarios que desean comenzar a usar los dispositivos **Kontrolog Max** o **Kontrolog Mini** sin necesidad de programar manualmente.

Aquí encontrarás los archivos necesarios para actualizar el dispositivo y simular su pantalla HMI de forma sencilla, sin escribir una sola línea de código.

> ✅ **Ideal para todo tipo de usuarios: técnicos, estudiantes, integradores y entusiastas.**

---

## 📦 ¿Qué contiene esta rama?:

* 🔧 Archivos `.bin` para cargar el **firmware precompilado** en el dispositivo.
* 🖥️ Archivos `.hmi` para simular la pantalla HMI táctil desde tu computador.
* 📹 Enlaces a tutoriales en video para guiarte paso a paso en la instalación y uso.

> Cada versión de Kontrolog (Mini y Max) cuenta con su propia carpeta.

---

## 🛠️ ¿Cómo se usa?:

### 1. ⚙️ Cargar el firmware

* Utiliza el software recomendado **Flash Download Tool** para grabar el archivo `.bin` en tu dispositivo Kontrolog.
* Sigue el video tutorial correspondiente para evitar errores de configuración.

### 2. 💻 Simular la pantalla HMI

* Abre el archivo `.hmi` en el programa **Nextion Editor**.
* Desde allí podrás simular la interfaz táctil del Kontrolog y configurar parámetros básicos.
